One-time Supabase database setup

The entire website is in this HTML file. Supabase tables and security rules cannot be installed automatically from a public webpage. Back up your database first. This clean setup replaces the four empty Fire & Ice tables, creates the employee-repair function, and preserves Supabase Auth accounts. If these tables contain data, the SQL deliberately aborts. Before registering, copy this SQL into Supabase → SQL Editor and run it once after backing up existing data. It can modify existing Fire & Ice tables and policies.

Uses your configured Supabase project. Never paste your service-role or secret key into this file.

Getting a missing clock_action(p_action) error? Your website cannot create server-side functions. Click Copy v3 time-clock SQL below. Go to your Supabase SQL Editor, create a new query, paste and run the SQL. Wait for Success, then refresh this website. Do not run the Full setup SQL on an existing database with records.

Existing database with working accounts? Use the Rate history upgrade SQL button instead of rebuilding tables. This upgrade preserves saved records and allows multiple hourly-rate changes on the same day. The website calculates daily overtime automatically without new database columns.
